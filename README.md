# 外壁と足場の数量の目安（試作）

国土交通省の 3D 都市モデル PLATEAU の建物の形から、外壁（北・東・南・西の向きごと）・屋根・足場の面積の目安を出す Web アプリの試作です。外壁塗装や大規模修繕の現地調査の前に、見積書の面積が妥当かを確かめる目安に使います。計算は全部あなたの閲覧器の中で行います（地図と建物の区画は、表示している範囲の分を公開の配信から取ります）。住所で探す時だけ、入れた住所の文字を国土地理院の住所検索へ送ります。

- 開く: https://driedsandwich.github.io/plateau-facade-quantities/
- 現地調査の前の目安です。実測ではありません（箱の形では出窓・バルコニー・庇は入りません。値がありえない時は警告を出します）。
- 画面は、推奨の見本（地球儀）で仮に組んだ試作です。見た目はまだ変わります。

## 使い方

1. 住所を入れるか、地図の建物を 1 回押します（押しても料金はかかりません）。
2. 外壁（向きごと）・屋根・足場の面積の目安と、隣と接して引いた壁が出ます。
3. 見積書の面積を入れると、目安の幅と比べた比が出ます。

## 出典とデータ

- 出典：国土交通省 PLATEAU（3D 都市モデル・建築物 LOD1・LOD2・墨田区ほか）を加工して作成。利用条件は PLATEAU サイトポリシー（公共データ利用規約 第1.0版・CC BY 4.0 と互換）。
- 地図：地理院タイル（淡色地図）。ジオイド高は国土地理院のジオイド高計算による値を同梱。住所の検索は国土地理院の住所検索。
- 閲覧器が直に取りに行く先：api.plateau.reearth.io・assets.cms.plateau.reearth.io・api.plateauview.mlit.go.jp・cyberjapandata.gsi.go.jp・msearch.gsi.go.jp（住所で探す時だけ）。
